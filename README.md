# User Analytics Dashboard (Full-Stack MERN)

A production-ready full-stack user analytics platform designed to track, aggregate, and visualize user activity in real time. Built with a robust Node.js/Express backend and a responsive Vite + React frontend.

## 🛠️ Tech Stack

* **Frontend:** React, Vite
* **Backend:** Node.js, Express.js
* **Database:** MongoDB, Mongoose
* **Deployment:** Vercel (Frontend), Render (Backend), MongoDB Atlas (Database)

---

## ✨ Key Features

* **Real-time Event Tracking:** Captures user actions and streams them directly to the database.
* **Aggregated Analytics:** Computes metrics and usage patterns efficiently.
* **Responsive UI:** Clean, dashboard-style interface optimized for all screen sizes.
* **Secure Environment:** Protected backend routes and environment variable isolation.
